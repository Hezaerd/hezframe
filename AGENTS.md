# Shore

`src/` contains the app, written in React and TypeScript. `app/` contains `index.html`, `style.css`, the Tizen adapter `device.js`, the owner-editable `config.js` and the bundled assets. Vite compiles `src/` into `dist/web/shore.js` and copies `app/` beside it. Read `docs/development.md` and `docs/interaction-behaviour.md` before app changes. For a new contributor or a separate TV installation, also read `docs/for-agents.md`.

Change behaviour through the typed model in `src/model/`: actions go through the pure reducer, and storage, device, image, font and timer work runs at the edges in `src/platform/` and `src/controllers.ts`. Components in `src/view/` render from the store and read the DOM only to measure it. Browser checks drive the app through `window.ShoreQA` (`src/qa.ts`); keep the state shape it reports. Target Chrome 85 in the production build. Node tooling can use modern JavaScript. Preserve remote focus/navigation, preference migrations and cached rendering. Read `docs/assets.md` before changing images, glass geometry or icon sizing; keep live blur and pixel analysis off the TV animation path.

Use `npm run format` and keep Oxlint warnings at zero (see `docs/tooling.md`). Run `npm run check` for app changes; it includes the model's unit tests. For interaction changes, run the browser preview and `CLEANFRAME_PUBLIC_FONTS=1 npm run check:browser`; public contributors must not need proprietary fonts. Run `npm run check:public` and `npm run export:public` before preparing a public download. Follow `CONTRIBUTING.md` and retain third-party notices.

Browser/repository tasks do not authorise device access. Read `docs/tv-status.md` before compatibility claims and `docs/agent-tv-setup-guide.md` before a new TV setup. An explicit device task is required even for queries that stage a helper. Announce any installation, app launch or restart; confirm visible results with the owner. Treat native Home/startup writes as a separate task with explicit authority and an exact-value recovery baseline.

On the maintainer's TV, preserve the stable package/application identity, author certificate and existing native Home assignment. For an independent user's installation, generate their own identity and certificates, and update manifest checks, launch/self-filter IDs and helper targets consistently. `scripts/package.py`, `scripts/tv.py` and `scripts/native-home/` contain reference-machine assumptions; they are not an unattended installer.

Keep proprietary fonts, signing keys, passwords, device identifiers, addresses, SDKs, recovery values and generated packages in ignored `.local/` or `dist/`. Never commit paid font binaries or publish a private-font widget. Public-code licensing does not replace the terms in `THIRD_PARTY_NOTICES.md`.

Use the contributor's own authenticated GitHub account. Preserve shared or uncommitted work. Use reversible deletion; never reset, force-push or rewrite history without explicit authority. Publication/visibility changes require a separate instruction.
